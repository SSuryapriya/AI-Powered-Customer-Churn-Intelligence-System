# 🚀 AI-Powered Customer Churn Intelligence Dashboard

## 📌 Project Overview
The **AI-Powered Customer Churn Intelligence Dashboard** is an end-to-end Data Analytics project developed using **SQL, MySQL, Power BI, and DAX**. The dashboard analyzes customer churn behavior in a telecom company and provides interactive business insights to help organizations improve customer retention and make data-driven decisions.

---

## 🎯 Project Objective
- Analyze customer churn trends.
- Identify factors contributing to customer churn.
- Monitor customer retention KPIs.
- Provide actionable business insights.
- Build an interactive dashboard for decision-makers.

# 🔍 Key Business Insights

- Customers with **Month-to-Month contracts** have the highest churn rate.
- **Fiber Optic** users are more likely to churn than DSL or Cable users.
- Nearly **27%** of customers have churned.
- Customers paying higher monthly charges show higher churn probability.
- Competitor-related reasons are the leading cause of customer churn.
- Long-term contracts significantly improve customer retention.

---

# 💡 Business Recommendations

- Encourage customers to switch from Month-to-Month to yearly contracts.
- Improve Fiber Optic service quality.
- Launch customer loyalty and retention programs.
- Offer personalized discounts to high-risk customers.
- Monitor churn trends regularly using interactive dashboards.
